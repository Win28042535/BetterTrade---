# BetterTrade 2026 — Persona Ranking Display

หน้าจอ 1920×1080 แสดงอันดับตัวตนนักลงทุน (12 persona) — **ต้นแบบดีไซน์ (prototype)** ไม่ได้เชื่อมข้อมูลจริง

ดูออนไลน์: https://bettertrade-ranking.vercel.app

## สิ่งที่จอแสดง
- ตัวเลขเป็น **ข้อมูลจำลอง** เริ่มจากยอดตัวอย่าง แล้วเพิ่มขึ้นเองเรื่อยๆ เพื่อให้เห็นแอนิเมชัน
  - แต่ละตัวตนขยับคนละจังหวะ ไม่เกิน 1 ครั้งต่อ 10 วินาที พร้อมป้าย +N
  - ทุก 20–30 วินาที มีตัวตนหนึ่งแซงขึ้น 1–3 อันดับ
  - ทุก 1–2 นาที อันดับ 2 แซงอันดับ 1 (การ์ดลอยสลับ)
  - ยอดรวมเกิน 2,000 จะเริ่มใหม่จากยอดตัวอย่าง เปิดทิ้งไว้ทั้งวันได้
- กด **F** เพื่อเต็มจอ

## ต่อข้อมูลจริงภายหลัง
ปิดส่วน "simulated data" ท้ายสคริปต์ใน `index.html` แล้วเรียก `render({counts: {...}})` ด้วยยอดจริงแทน
คีย์ตัวตน: `guardian` `harvester` `steadyhand` `diamondhand` `analyst` `planner` `explorer` `sage` `maverick` `waverider` `contrarian` `collector`
