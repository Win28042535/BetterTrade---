# BetterTrade 2026 — Persona Ranking Display

หน้าจออันดับตัวตนนักลงทุน (12 persona) สำหรับจอในงาน

- จอ 16:9 (1920×1080): https://bettertrade-ranking.vercel.app/?screen=16x9
- จอ LED 4:1 (4096×1024): https://bettertrade-ranking.vercel.app/?screen=4x1

## ตัวเลข
- ฐานคือยอดจริงจาก `https://investor-dna.efin.finance/api/investor-dna` อ่านใหม่ทุก 60 วินาที ผ่าน rewrite ใน `vercel.json` (API นั้นไม่เปิด CORS)
- แต่ละตัวตนจะขยับเพิ่มเติมจากยอดจริงไม่เกิน ±50 คน เพื่อให้จอเคลื่อนไหวตลอด ดังนั้น**ตัวเลขบนจออาจไม่ตรงกับยอดจริง** และ % คำนวณจากตัวเลขบนจอ
- `?jitter=0` แสดงยอดจริงตรงๆ ไม่มีการขยับเพิ่ม (ปรับกรอบได้ เช่น `?jitter=20`)
- ถ้าเรียก API ไม่ได้ (เช่น เปิดไฟล์จากเครื่อง) จะใช้ตัวเลขล่าสุดที่อ่านได้ หรือ `SNAPSHOT` ใน `index.html`

## ปุ่มลัด
- **F** เต็มจอ · **S** สลับขนาดจอ · **H** ซ่อน/แสดงปุ่มสลับขนาด
